# 提示词版本快照

`current.json` 保存助手最近一次提示词提交时，应用实际生效的动作配置，包含动作名称、启用状态、优先级和规则。

该文件用于 Git 对照和回退，不由应用自动读取。运行时仍使用 `data/outputs/action_recognition/prompt_config.json`。

比较不同提交中的 `current.json` 可以查看每轮微调差异。需要恢复时，将对应提交的 JSON 填入动作识别页面的配置 JSON 编辑器并保存。仅切换 Git 提交不会自动覆盖 data 目录中的运行配置。

快照不包含图片、裁剪、推理结果或模型权重。没有人工标注评测时，提交说明只描述规则变化，不宣称准确率提升。

Head 模式使用独立的 `data/outputs/action_recognition/head_prompt_config.json`，首次创建时从完整动作配置复制抬头、低头规则，此后互不覆盖。其默认配置为 `action_recognition/default_head_prompt.json`；`head_current.json` 是本次拆分时的实际配置快照，后续提交前需再次同步。前端配置模式选择器只切换编辑对象；实际推理是否采用 Head 配置仍由“只测抬头低头”开关控制。

## 2026-11-05：精简规则与明确动作边界

- 恢复实际配置中被数字占位替换的抬头规则；抬头、低头依据头部方向，不以托腮、坐直或遮脸代替方向证据。
- 总规则集中处理目标归属、观看对象和证据不足的退回策略，删除重复的历史标签修补说明。
- 手机允许静态观看、部分遮挡和黑屏，但必须有设备及观看关系；平板须有设备形态证据，不能只凭黑色矩形。
- 写字限定纸面持笔书写位置，明确排除平板触控笔及仅持笔看手机；看书排除符合写字的姿态。对象无法区分时不靠优先级猜测。
- 睡觉继续表示趴伏、明确闭眼或埋头的可见姿态，不确认真实睡眠；当前配置优先级由 55 调为 100，避免被普通低头覆盖。单帧闭眼不能排除眨眼。
- 保留实际配置中的动作名称、开关和其余优先级；默认配置和实际配置采用相同的本轮规则，实际配置完整保存于 current.json。
- 本轮仅检查配置、提示词组装和合成测试，不运行真实图片推理，不宣称识别率提升。
