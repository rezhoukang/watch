行为标注：只导入人体置信度 >0.7 的 Pose 框，举手自动预标，其余选择低头 / 抬头 / 正常 / 无法判断。每人一个状态，可人工纠错。

点缩略图进入全屏标注 → 预标注 → 改框/加框 → 保存。

多模态模式：按人头裁剪后使用 VLM 动作分析，读取“动作识别”页已保存的提示词。固定 Qwen3-VL 4B、4-bit、A 基线，裁剪比例 0.85 / 0 / 1.30；不运行 Pose 动作规则，首次需要加载本地模型。

人脸识别固定：SCRFD 人脸置信度 0.5 · 识别阈值 0.3 · 质量门槛 0.5 / 24px / 50（已锁死，不开放输入）。

姿势检测固定：yolov8m-pose.pt · 置信度 0.6 · imgsz 640 · 低头 R < 0.05 · 抬头 R > 0.20 · 全图物体检测与关联（Pose 框）开启 · 物体置信度 ≥ 0.03。举手优先，无法判断的姿势直接排除。

目标检测固定用「图片推理 → 目标检测」那套：medium.pt 0.45 为基准 + RT-DETRv4 0.25 补齐，合并 IoU ≤ 0.1、自定义 IoU 生效置信度 > 0.55（已锁死，前端不开放）。绑定固定为链式贪心 + 一一对应：只保留 IoU > 0 的配对，按 IoU 降序占位（IoU 相同时中心距离近的先占），一个人头最多绑一个姿势。结果只画 head 框，姓名与姿势状态都挂在这个框上。
